# Исторический прогон Modified QA13 и последующие сравнения

Это исторический снимок QA13, дополненный более поздними сопоставимым Original и частным A/B. Общий флаг приёмки и публикация здесь не заявлены. Последующие согласованные исключения модов требуют отдельного прогона нового замороженного состава; результат QA13 или A/B не является его runtime PASS. Историческая проверенная композиция имела lock SHA256 `2f48c9e63e105ccd8fc82239b0a6504c14e6678f135f3d0732b709e57f586599`: Minecraft 1.20.1, Forge 47.4.0, 541 поставляемый JAR: 540 неизменённых авторских и один разрешённый русский производный Verity. Все 431 исходных авторских JAR ATM9 сохранены побайтно. Хеши 542 runtime JAR вместе с инфраструктурой совпадают до и после запуска.

Новый мод Verity 6.0.0 локализован по прямому разрешению пользователя как 6.0.0-ru.1. SHA256 авторского входа: `f76f641f17ea3e3b2e8486596790ae65c27c2b016fae6ed8557c67887816b7d0`; поставляемого русского JAR: `45fc05ee600c24e989a5a2c17fab099fa5bd15415ee9d848e73885e8f42b85d8`. Это явно раскрытая замена нового мода, не BASE. Предыдущая ограниченная нативная проверка подтвердила структурную неизменность 531 игрового метода; она не заменяет проверку каждой способности в игре.

Использована изолированная Debug-сборка опубликованных исходников лаунчера 420, revision `b130ef14f0fd9c8dfdca9e3dcc3bb916e1b8d8dc`, DLL SHA256 `b3862b052ab9d51e13e81e7f8b5f5b5685c12316b04d6075e3786f3b896a3d20`. Это не проверка побайтовой идентичности публичному EXE. Диагностический агент protocol 7, SHA256 `758f27290e815a433e76cf926bc842435fe4dc1fcb31074924a6158db6b5b8f2`, не содержит трансформера классов и не поставляется как мод.

В отдельном техническом экземпляре нативно создан новый мир с seed `-921803102721574764`, структурами и без бонусного сундука. Старый мир не копировался, шаблон NBT не менялся. Частные условия QA: Creative с командами, русский язык, `pauseOnLostFocus=false`, `-XX:-OmitStackTraceInFastThrow`, применение настоящего сервиса пресета управления к уже инициализированным options. Графика, дистанции, звук, микрофон, игровые эффекты и проверки форматов диагностикой не менялись.

Три последовательных нативных наблюдения подтвердили главное меню, затем три подтвердили игрока, уровень и закрытый встроенный сервер без GUI/overlay. Получены пять действительных русских строк и действительный ресурс предупреждения из KubeJS. Пресет содержит 682 назначения: все 682 совпали с нативными getters в главном меню и со штатно сохранёнными options после выхода. Это доказательство повторного запуска с инициализированными options; первый запуск пресета и остальные перезапуски здесь не объявляются проверенными.

Естественно появившаяся `verity:box` прошла нативный путь модели/анимации. После единственной разрешённой команды `summon verity:box ^ ^ ^3` подтверждены новый серверный экземпляр и три последовательных возрастающих времени существующей модели и её entity-manager: `63.5598748 → 128.6798747 → 193.5598754`. ID существующей модели совпадал с текущей сущностью. После третьего образца мир оставался здоровым ещё 256,9 секунды. Это доказывает вход в render/animation path, но не полную отправку вершин, итоговый GPU draw или визуальное качество. Исторический QA11 `ArrayIndexOutOfBoundsException` при рендере Box не повторился; исправленным он не объявлен. Эти Box-наблюдения относятся к QA13, а не к последующим изменениям состава.

После трёх здоровых наблюдений мира на 3,21 секунды включён синхронный GL debug с сохранённым родным callback. Из 12 ограниченных попыток получен один уникальный JNI-стек: `GL30C.glBlitFramebuffer → RenderTarget.copyDepthFrom (m_83945_, строка 94) → LevelRenderer.roundabout$setDepthbuffer → roundabout$renderShaders2`. Он устанавливает источник конкретного захваченного сообщения `173538523`. Исходный `SYNC=false`, pointer callback и нейтральный logging tap восстановлены/сняты до команды Box. Форматы, размеры, число samples и ID исходного/целевого FBO не измерялись. Все остальные Generic GL сообщения этому стеку автоматически не приписываются.

Игра завершена обычным нативным `Minecraft.stop`, все измерения сохранены. Java вышла с кодом 0 в `2026-10-30T02:36:36.563Z`. Её процесс, процессы собственного AI backend и listener его порта после выхода отсутствовали. Принудительного завершения не было.

Полный исторический лог QA13: 25 011 017 байт, SHA256 `d5f665d725304008d18b81cd98262339ccff8bdbbb6177fdfd94d05474c5351f`. Он начинается текущим запуском и заканчивается штатным сохранением/выходом; ротации не потребовалось, архив предыдущего остановленного staging-запуска исключён. Неопознанных timestamp-заголовков нет. Зафиксированы **134 ERROR, 0 FATAL**: 100 до загрузки мира, 4 во время загрузки, 29 после присоединения, 1 при завершении. Изменение числа сообщений не является измерением частоты ошибок. ## Явное обновление выводов последующими прогонами

**Сопоставимая текущая Original 1.1.1** (revision `0555209ec4e4b1ad9953471bbbecc22a17c0acb8`, все 431 BASE JAR побайтно те же) прошла три нативных состояния меню и нового мира, 510,5 секунды здорового мира, штатное сохранение и exit 0. Полный лог: 4 002 097 байт, SHA256 `ab89da7cf2ca0452fbbfe741e616deda82d691184ceaea5b9d2aba9984eff324`, 96 ERROR / 0 FATAL. Exact OpenAL ERROR был в 08:40:12 до выхода в 08:43:55. Это перекрывает старое ограниченное утверждение «не было в измеренном baseline»: ошибка не уникальна для Modified. Общие некритические случаи приняты пользователем как фон; их наличие не доказывает намеренность или безвредность всех 96 строк. Четыре GTCEu potion empty-input случая также общие, с нативным суффиксом-счётчиком 165…168 против 169…172.

**Частный A/B убрал один Roundabout**, SHA256 `5f27650d19f20c4e4b0cddbe947a304328a3767bc3f1ad7c8f6ad7382daf050b`, без обязательных зависимых. Остальные 1926 исходных файлов совпадают. Сравнение именно runtime JAR до запуска также подтвердило: 542 → 541, ровно один отсутствующий Roundabout, все остальные 541 JAR, включая E4Steam, совпали по SHA256. Это побайтовая проверка всей поставки; она отдельна от анализа методов Roundabout/Jade и прежней структурной проверки 531 игрового метода локализованного Verity.

После трёх здоровых состояний A/B наблюдался 543,5 секунды, сохранился и завершился штатно с кодом 0. Generic GL `173538523`: 0 против 30 475 в QA13; Jade NPE: 0 против трёх заголовков QA13; шесть существующих `f_105191_` были non-null `BlockPos`, без чтения XYZ/singleton. Blood Magic / Curios сохранила два ERROR. Исторические результаты поддерживают удаление Roundabout для наблюдавшихся GL/Jade случаев, но не устраняют все новые ошибки и не проверяют последующий изменённый состав.

В A/B добавлены только частные read-only наблюдения и авторский logging-флаг ModernFix, не меняющий eviction policy; GL sync/AL-запросы/качество/аудиоустройства не менялись. Полный A/B лог: 23 680 186 байт, SHA256 `914ad1c78e9333fab8dc6c6dcd3f1b1adb0820d5552d9c65a6b3eeecb7f5b36d`, 145 ERROR / 0 FATAL. Новых нормализованных ERROR-сигнатур относительно QA13 нет: нормализованы только Java object identity и elapsed время JEI. Различия суммарных чисел не являются измерением частоты сбоев. Актуальный runtime PASS после согласованных исключений должен быть записан отдельно.
