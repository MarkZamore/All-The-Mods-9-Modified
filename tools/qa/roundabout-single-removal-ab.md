# Частная проверка удаления одного Roundabout

В отдельной копии Modified удалён только `Roundabout-forge-1.20.1-3.6.2.jar`, SHA256 `5f27650d19f20c4e4b0cddbe947a304328a3767bc3f1ad7c8f6ad7382daf050b`. Обязательных зависимых модов по всему проверенному графу нет. Остальные 1926 исходных файлов совпадают побайтно с текущей Modified, lock `2f48c9e63e105ccd8fc82239b0a6504c14e6678f135f3d0732b709e57f586599`; все 431 BASE JAR сохранены. Производственная сборка, её locks и публикация не менялись.

Minecraft 1.20.1 / Forge 47.4.0, Java 17, 12 GiB heap, русский язык, тот же seed и нативно созданный новый мир. Использована та же изолированная Debug-сборка исходников лаунчера 420 с DLL SHA256 `b3862b052ab9d51e13e81e7f8b5f5b5685c12316b04d6075e3786f3b896a3d20`. Диагностические различия раскрыты: штатный флаг ModernFix `debugDynamicSoundLoading=true` печатает имена удаляемых из кеша звуков; частный агент шесть раз прочитал существующее поле `MultiPlayerGameMode.f_105191_`. Поле, игровые объекты и графические/аудионастройки не изменялись. Синхронный GL debug, команды, AI chat и PTT здесь не включались. Новые классы не поставляются как моды и не трансформируют игровой bytecode.

Три нативных здоровых состояния меню и мира подтверждены. После них мир без GUI/overlay наблюдался ещё 543,5 секунды. Штатный `Minecraft.stop` сохранил все измерения; Java завершилась с кодом 0 в `2026-10-30T04:21:23.032Z`. Принадлежащие прогону AI-процессы остановились, endpoint закрылся.

| Проверяемый случай | Полная Modified с Roundabout | Частная копия без Roundabout |
| --- | ---: | ---: |
| Generic GL `173538523`, native callback INFO | 30 475 | 0 |
| Три заголовка пойманной Jade NPE / null BlockPos | 3 | 0 |
| Blood Magic / Curios Optional + chat overlay | 2 | 2 |
| `f_105191_` в шести начальных нативных чтениях | Ранее null доказан стеком Jade и её getter | 6 из 6 non-null `BlockPos` |

Для Generic GL предыдущий синхронный JNI-стек указывал на Roundabout depth blit. Для Jade проверены нативный getter поля и overwrite Roundabout, записывающий null. Удаление одного JAR вместе с этим кодовым доказательством подтверждает связь Roundabout с двумя наблюдавшимися сбоями в данных условиях. Точное значение singleton/sentinel или координаты BlockPos не читались. Форматы framebuffer также не измерялись.

Удаление Roundabout можно рекомендовать для этих GL/Jade случаев, если пользователь готов отказаться от содержимого самого мода. Это не исправляет Blood Magic и другие новые ресурсные ошибки. Удаление мода из уже существовавшего мира может оставить его registry ID; сохранность старых миров этим новым тестовым миром не проверена.

Штатная диагностика ModernFix дала 210 сообщений об удалениях кешированных звуков. Две ошибки OpenAL непосредственно предшествовали сообщениям того же Render thread:

- `09:16:52`: `minecraft:sounds/minecart/base.ogg`;
- `09:18:56`: `minecraft:sounds/mob/bee/loop4.ogg`.

Нативный код печатает `Evicted sound` после callback удаления `SoundBuffer`. Поэтому установлена связь ошибки с этими удалениями кеша. Состояние прикреплённых AL buffers и возможность ранее оставленного sticky AL error не измерялись; новых `alGetError` и иных AL-вызовов диагностика не добавляла. Эта ошибка уже воспроизвелась в чистой Original и принята пользователем как общий некритический фон. Удалять новые моды ради неё не рекомендуется.

Полный лог: 23 680 186 байт, SHA256 `914ad1c78e9333fab8dc6c6dcd3f1b1adb0820d5552d9c65a6b3eeecb7f5b36d`, **145 ERROR, 0 FATAL**. Большее суммарное число ERROR не означает ухудшения: количество перезагрузок ресурсов и таймерных диагностик различается. Новых нормализованных ERROR-сигнатур относительно полного diag13b нет; нормализованы только адреса Java-объектов и время уведомлений JEI. Остались две shader-link и 42 uniform callback строки тех же сигнатур, что в текущей Original.

Полное устранение новых ошибок, исторического Box-падения, визуальная оценка, все способности и два Steam/LAN-клиента не заявлены.
