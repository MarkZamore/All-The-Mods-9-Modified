# Verity JE Russian Translation resource layer

Requested third-party project: [PAGODI on CurseForge](https://www.curseforge.com/minecraft/texture-packs/verity-je-russian-translation-rusifikator), project1774624, [file9375140](https://www.curseforge.com/minecraft/texture-packs/verity-je-russian-translation-rusifikator/files/9375140), release `Verity JE-RU-1.20.1-v6.0.0` for Minecraft1.20.1, uploaded2026-10-30. The project lists All Rights Reserved. This is the translation project's own official download, not a release by Verity's author.

The original `Verity-JE-RU.zip` is383380bytes, SHA256 `de15104f3ea81fe2ba50116c65f3d74e29692cefbc6ef68192244a7c64740b68`. Store it unchanged at `kubejs/assets/Verity-JE-RU.zip` as one support resource. Existing KubeJS2001.6.5-build.16 reads top-level ZIPs there through its native `GeneratedClientResourcePack.inject` and `FilePackResources`. No activation script, additional JAR, DefaultSettings edit or launcher rule is needed. Commit the support ZIP before strict restore; its absence is an error, not a trigger to fetch latest. The current Git ignore rules permit this path.

The ZIP contains only a29-key `assets/verity/lang/ru_ru.json`, format15 metadata and a512×512 selection icon. It adds10 keys and overlaps19 of the approved Russian JAR's21 keys:6 values match and13 differ. In particular, several labels use «Истина» instead of «Verity». Some new entries name legacy or configuration aliases; presence is not proof of a current UI caller. This partial language layer cannot translate Java-coded dialogue, screens or voice. Keep `verity-6.0.0-ru.1.jar` unchanged.

Native resource stacking merges the layer: the two existing Russian keys absent from the ZIP remain available. The ZIP has no English locale, and native selected-English values remain those of the approved JAR. Both versions of all19 overlapping strings have no `%` markers; native `String.format` passed all29 values.

Personal options and selected-pack lists are not rewritten. The existing KubeJS insertion boundary is the first `FilePackResources` ZIP; later personal ZIP packs retain priority. Directory packs using `PathPackResources` are not recognized by that boundary, so universal precedence for personal directory packs is not promised. This preserves the existing KubeJS mechanism rather than adding a new selection policy.

`verity-je-ru-resourcepack-native.json` records actual Minecraft1.20.1 pack-metadata serialization, `FilePackResources`, `MultiPackResourceManager` and `ClientLanguage` checks. `NativeResourceLanguageProbe.java` is the source-only probe; compile against the exact1.20.1 SRG/Forge47.4.0 dependencies, Gson, FML core and vanilla client resources, then pass the approved Verity JAR, original ZIP and output JSON. It creates no Minecraft client, game window or input. It does not prove the new ZIP's complete in-game Mixin lifecycle or rendered pixels. Additional in-game verification for this resource-only addition was explicitly waived by the user.

The resource addition does not fix or test the separate Soul Eater crash. Root owns final composition, lock/count updates, source publication and migration. No active source or lock was modified in this preparation.
