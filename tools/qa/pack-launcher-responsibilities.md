# Что находится в сборках и что осталось лаунчеру

Область: ATM10, TerraFirma Rebirth2, Minecraft26.3, Caves and Dungeons, ATM9 и ATM9 Modified. Лаунчер421 [f9b8967](https://github.com/MarkZamore/LANMinecraft/commit/f9b8967d6d0a5a1e20064feca843cf4c48d9d36a) опубликован: [CI503/503](https://github.com/MarkZamore/LANMinecraft/actions/runs/41312377974), реальный публичный EXE и delta420→421 проверены по SHA. Публичный byte/delta-verifier отдельно не запускал EXE; Singleplayer532 измерен frozen Debug reference SHA`bcb994f7e5b95597b22df4cdd7f1e61d5b255826be9e29d1f8961a7e4241a599`, native file version1.0.1.0/product1.0.1+b130ef14f0fd9c8dfdca9e3dcc3bb916e1b8d8dc. Рабочий source содержит проверенный421 preflight fix, но эта сборка не побайтно публичный421 или будущий422 EXE. Проверка поставки, клиентский прогон и совместный Steam-тест имеют отдельные доказательства; одно не заменяет другое.

## Что принадлежит сборкам

- Конфиги модов, ресурсы, переводы, пресеты управления и фиксированные JVM-параметры. Логирование задают `config/log4j2.xml` и `launcher/jvm-args.txt`, сохраняя ERROR. Приоритет JVM-параметров исправлен общим сборщиком аргументов: значения из pack-файла ставятся перед игровой main class после native defaults, остальные аргументы сохраняются.
- Квестбуки ATM9/Modified и ATM10 используют русский при выбранном `ru_ru`; английский и остальные языки не заменяются русским принудительно. Ручные дополнения привязаны к английскому fingerprint. При подготовке будущего обновления подтверждённый свежий author/community RU заменяет ручной fallback; изменившиеся строки попадают в отчёт, а не блокируют импорт новой авторской сборки.
- Неизменённый community Verity JE-RU ZIP PAGODI (29частичныхRUkeys) принадлежит `kubejs/assets/Verity-JE-RU.zip`; существующий native KubeJS assets ZIP loader подключает его без activation JS, записи personal pack-selection и правила C#. Он не заменяет одобренный RU JAR; source/static/native language proof раскрывает coverage и WAIVED дополнительную игру только для resource-only дельты.
- В Modified recipe и SHA закрепляют переносимые Ollama/модель; KubeJS задаёт AI-поля Verity, отключает согласованные автоматические убийства и удаляет только неверные disc-ID из тега. Русский Verity и Grotesque quiet — явно разрешённые производные JAR; AllTheLeaks1.1.4 — закреплённая официальная BASE-замена, сохраняемая source workflow при следующих author imports. Это не скрытые правила C#.
- Верхняя панель Memory Settings отключается native client-скриптом самой ATM9/Modified. Он меняет только загруженный `disableWarnings`, сохраняет личный JSON, прочие поля и выбранный heap. Ранний low-heap Swing/constructor log этой client-stage политикой не убирается. После author import шаблоны восстанавливаются до strict restore, действительные native API проверяются после появления JAR.
- В [ATM10 28f3f5c](https://github.com/MarkZamore/All-The-Mods-10/commit/28f3f5c84a595c79ba99c1e1590e6cebb4ffca1f) находятся RAM-политика и наш адресный KubeJS workaround для ATM10 8.4: только loaded `ImmediatelyFast.config/runtimeConfig.hud_batching=false`, с сохранением личного файла и3D HUD Draconic Evolution. AdvancedAE остаётся авторским, собственная правка регистрации меню снята.
- В ATM9/Modified добавлен официальный сторонний Draconic Evolution Render Patcher1.3.0, сохраняя BASE JAR и3D assets; это не наш переписанный renderer. В Modified добавлен авторский Weather2 2.8.3 с прежними defaults. Его tornado/fire/snow/sand изменения не имеют обещанной FTB claim-защиты; собственный Safety запрещён пользователем и не добавлен. Отдельный DE in-game/визуальный тест пользователь разрешил не проводить; это WAIVED, не визуальный PASS.
- В [Minecraft26.3 20badd1](https://github.com/MarkZamore/Minecraft-26.3/commit/20badd173a215d2c1ba99978647f4e5090d9797f) добавлены только Iris1.11.7 и Sodium0.9.3-beta.1: без выбранного за игрока shaderpack и без новой игровой политики лаунчера. TFR2 сохраняет чистый авторский контент; совместимость CustomSkinLoader обеспечивается data-only `version.json` и JVM-параметром сборки. Фиксированный заголовок **TerraFirma Rebirth2** также находится в её `launcher/jvm-args.txt` как `-Dminecraft.portable.identity.windowTitleText=TerraFirma Rebirth 2`: общий `CompleteJvmArguments` даёт pack-значению приоритет перед папочным fallback.

Промежуточное окно и лишняя кнопка LAN убраны **в готовых e4steam JAR**: [профиль `native-lan-ui-v1`](https://github.com/MarkZamore/e4steam/blob/67d722fdafaec3424fc0f4a3ef714870d263a339/profiles/native-lan-ui-v1.json) выбирает шесть современных производных и13 побайтно авторских старых. Сетевые классы/приглашения сохранены; лаунчер устанавливает проверенный артефакт и не переписывает его при запуске. Отдельные runtime hooks вызывают штатную публикацию/«Жалобы», как раскрыто ниже.

Собственные ограничения дальности рендера, симуляции, теней и отдачи чанков убраны. Сохраняются native аппаратные/форматные проверки, авторские defaults и выбор игрока. Принуждение ModernFix и прежний глобальный игровой HTTP-таймаут сняты; старые runtime обходы Xaero/FTB и SolarFlux выключены. Выключенные возможности не выдаются за текущие изменения сборки.

## Отдельная сетевая задача и следующий лаунчер

Реальный мультиплеер по Steam остаётся открытой задачей для ATM9/Modified и условием завершения текущей цели. Отдельная удачная попытка Direct LAN не является Steam PASS или сетевой приёмкой Modified. Последний свежий Steam-сценарий остановился до login с ConcurrentModificationException без полного стека; конкретная причина ещё не доказана. Старое согласование отложить совместный тест не закрывает этот уже воспроизведённый сбой.

Срез подготовки01.11.2026 до публикации422: общий discovery/dedup, разрешённое имя мира и UI-изменения проходят обязательные проверки; публичный результат422 этим документом не установлен. Доказанный UI-фикс касается пустого диапазона ScrollBar: прежний native Track скрывал Thumb даже при Visible. Добавлен неподвижный индикатор существующими токенами и ограниченная числовая диагностика viewport/extent/bounds после навигации. Точный live-триггер отсутствия полосы при переполнении ещё не установлен; диагностика не является его исправлением. Сетевой disconnect fix/PASS из подготовки422 не выводится. Текущее публичное состояние — в [workflow лаунчера](https://github.com/MarkZamore/LANMinecraft/actions) и [релизах](https://github.com/MarkZamore/LANMinecraft/releases).

У Original после родительского465 опубликован [диагностический source dba4b58](https://github.com/MarkZamore/All-The-Mods-9/commit/dba4b58c162bb06591bba3b00618a1d825095e6d), [CI41322238677](https://github.com/MarkZamore/All-The-Mods-9/actions/runs/41322238677). Единственная runtime-дельта — pack-owned `config/log4j2.xml`: ограниченный native Connection DEBUG capture в файл; Root/Console/прочие настройки не изменены. Публичные config ZIP/library/manifest и1805source-файлов проверены, но это наблюдение ошибки, не её исправление и не новый native game/network PASS. Прежний title-report c598 относится к родительскому runtime и не переименован в этот диагностический состав.
