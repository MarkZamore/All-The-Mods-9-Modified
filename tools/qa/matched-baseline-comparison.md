# Историческое сопоставление Original, QA13 Modified и одного A/B

Текущая Original 1.1.1 проверена заново: revision `0555209ec4e4b1ad9953471bbbecc22a17c0acb8`, все 431 базовых авторских JAR совпадают с BASE Modified. Modified соответствует lock `2f48c9e63e105ccd8fc82239b0a6504c14e6678f135f3d0732b709e57f586599`: 541 поставляемый JAR, включая 540 неизменённых авторских и разрешённый русский производный Verity. Продукционные файлы и состав этим сравнением не менялись. После него пользователь согласовал дополнительные исключения модов. Последующий изменённый состав здесь не проверен; общей приёмки или публикации отчёт не заявляет.

Оба клиента использовали Java 17.0.20.1, Forge 47.4.0, 12 GiB heap, одну изолированную Debug-сборку исходников лаунчера 420 (`b130ef14f0fd9c8dfdca9e3dcc3bb916e1b8d8dc`, DLL `b3862b052ab9d51e13e81e7f8b5f5b5685c12316b04d6075e3786f3b896a3d20`). Миры созданы штатным Minecraft с seed `-921803102721574764`, структурами и без бонусного сундука. Разные моды генерации означают, что один seed не гарантирует одинаковый ландшафт.

В обоих прогонах подтверждены три нативных здоровых состояния меню и мира, русский язык и штатный выход с сохранением всех измерений. Original оставалась в мире без GUI ещё 510,5 секунды после трёх здоровых состояний. В обоих прогонах не отправлялись AI chat/PTT и не выполнялись действия с микрофоном. Язык, `pauseOnLostFocus=false` и `-XX:-OmitStackTraceInFastThrow` были частными условиями QA. Графика, дистанции и уровни звука совпадают: render distance 11, simulation 10, graphics 1, VSync, mipmap 0, max FPS 120, master 1.0. Продукционному EXE и двум Steam/LAN-клиентам этим отдельная проверка не приписывается.

Разность 38 не означает 38 новых причин или модов. Числа зависят от фаз, количества перезагрузок ресурсов, таймерных уведомлений и времени наблюдения; частоту ошибок по ним не сравниваем. Точные сообщения и фазы сохранены отдельно.

По последнему решению пользователя общие некритические случаи Original приняты как допустимый фон. Это решение о границе работ, а не доказательство безвредности всех базовых ERROR или намерения авторов оставить их.

- **OpenAL `Deleting stream buffers: Invalid operation.` воспроизвелась в Original** в 08:40:12, во время здорового мира и до выхода в 08:43:55. Она также была в двух прогонах Modified, до их выхода. Удалять новые моды из-за этой строки оснований нет. Позднейший частный A/B с авторским logging-флагом ModernFix сопоставил два ERROR с непосредственными eviction того же Render thread: `minecraft:sounds/minecart/base.ogg` в 09:16:52 и `minecraft:sounds/mob/bee/loop4.ogg` в 09:18:56. Нативный callback удаления кеша установлен; точное состояние прикрепления buffer и sticky AL error не измерено. AL-запросы не добавлялись, исправление не заявлено. Аудиоустройства различались: новая Original использовала Razer Barracuda X (BT), старый diag13b — Cirrus Speakers, при одинаковом выборе default. QA устройства не переключала. Положительное воспроизведение на BASE остаётся доказанным; отрицательный аудиотест при разных устройствах не был бы достаточен.
- **Четыре GTCEu empty-input сообщения — общая базовая семья.** В Original это `quark.resilience_165`, `mundane_166`, `quark.resilience_167/168`; в Modified — соответствующие `_169…172`. Точный нативный генератор строит суффикс счётчиком `PotionBrewing` recipes. Изменённые числа сохранены в исходных данных, но не являются четырьмя доказанными новыми поломками.
- **Shader-link и unlinked-uniform GL сообщения есть в Original.** Она зарегистрировала 2 и 42 callback сообщения тех же точных сигнатур; Modified — 1 и 21. Это принятый общий фон. Новая Generic GL `173538523` в Original отсутствовала, в Modified зарегистрирована 30 475 раз как INFO native callback. Один ограниченный синхронный захват указал на `RenderTarget.copyDepthFrom → Roundabout setDepthbuffer/renderShaders2`; форматы FBO не измерялись. Последующий частный прогон без одного Roundabout зарегистрировал 0 Generic сообщений за 543,5 секунды здорового мира. Остальные 1926 исходных файлов и 541 оставшийся runtime JAR, включая E4Steam, совпали побайтно; это сильное подтверждение для данных условий, без измерения FBO форматов и без общей приёмки будущего состава.
- **Realms 502 не встречалась во всех сборках.** В перечисленных проверенных логах она была один раз в diag13b: внешний HTTP 502 вернул HTML, после чего клиент записал три ERROR. В другом полном Modified и в текущей Original её не было. TFR и ATM10 записывали другие ошибки авторизации Realms; ATM10 наблюдалась только до меню. По этим окнам нельзя объявлять сетевую 502 постоянной ошибкой любого модпака или рекомендовать удаление мода.
- **Blood Magic / Curios и Jade** пока наблюдались только в Modified: два связанных ERROR overlay и три заголовка одной Jade NPE. Неизменность базовых JAR не делает их автоматически базовым фоном. Для Jade установлены getter `f_105191_` и overwrite Roundabout с записью null; в последующем A/B без этого JAR шесть нативных значений были non-null и Jade NPE не появилась. XYZ или точный singleton не читались. Blood Magic сохранила два ERROR в этом A/B; вина конкретного нового мода в ней не доказана.
- **Grand Sigil — авторский детектор остановки кадров.** Три ERROR сопровождают явные watchdog dump при загрузке JEI и завершении. Они не доказывают, что сам Apex Arcana вызвал задержку. Удаление детектора только ради отсутствия его сообщений не рекомендуется. Таймерные строки JEI о продолжающейся регистрации также отделяются от исключений плагинов.

Ресурсы новых модов, их реальные callers, необязательные интеграции и обязательные зависимости разбираются отдельно. Присутствие неверного файла не означает, что соответствующая игровая возможность используется: например, у Born есть три старых idle-ресурса без прямых текущих ссылок, а Solo использует корректный `fly` для стандартного движения Kaiselin. Намеренность, достижимость и функциональный ущерб должны быть указаны раздельно. Общий список удалений нельзя считать гарантией «только базовые ошибки» до проверки оставшихся взаимодействий.

## Завершённый A/B и граница актуальности

Частный эксперимент удалил только Roundabout 3.6.2 (`5f27650d19f20c4e4b0cddbe947a304328a3767bc3f1ad7c8f6ad7382daf050b`), без обязательных зависимых. Это не применённое отчётом изменение публикации. В нём 540 поставляемых JAR + E4Steam; сравнение с родительскими 542 runtime JAR обнаружило ровно один удалённый файл, без других различий SHA. Методовые и read-only доказательства остаются отдельными: GL JNI caller Roundabout, getter/overwrite Jade, шесть non-null чтений поля. Показания sentinel/XYZ и полная визуальная проверка отсутствуют.

A/B прошёл нативные menu/world 3 samples, 543,5 секунды здорового мира, сохранение, exit 0 и завершение принадлежащего AI backend. Его 145 ERROR / 0 FATAL не означают 11 новых сбоев относительно QA13: новых нормализованных ERROR-сигнатур нет, а фазы/перезагрузки/таймеры различаются. Полный лог SHA256 `914ad1c78e9333fab8dc6c6dcd3f1b1adb0820d5552d9c65a6b3eeecb7f5b36d`. Generic GL и Jade в этом окне отсутствовали, Blood Magic и другие новые ресурсные семьи остались. Последующие согласованные исключения модов требуют отдельного итогового full-client/new-world прогона по новому lock; этот документ не выдаёт исторические измерения за PASS того состава.
